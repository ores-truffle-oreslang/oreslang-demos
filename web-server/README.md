# Web server demo

A small local HTTP server whose response bodies are generated by Oreslang programs.

Run:

```bash
bash run.sh
```

Then open:

- `http://127.0.0.1:8080/`
- `http://127.0.0.1:8080/health`

Set `PORT` to change the listener port. Set `ORESLANG_COMPILER` if the compiler launcher is not on `PATH`.

The Java shell owns only the JDK HTTP listener/routing boundary. `index.ores` and `health.ores` produce the actual response bodies. Each guest process is bounded by a 10 second timeout and only fixed source files can be selected by a route.

Validate the guest programs independently:

```bash
oreslang check index.ores health.ores
```
