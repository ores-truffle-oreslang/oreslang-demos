# Oreslang demos

Runnable example applications for Oreslang.

This repository is intentionally organized by application shape:

- `cli/` — a pure Oreslang command-line program.
- `desktop-app/` — an Oreslang program hosted by a minimal desktop window shell.
- `web-server/` — Oreslang response programs hosted by a minimal HTTP server shell.

The demos target the current `ores-truffle-oreslang/oreslang-source.java` language/runtime and use the internal executable name `oreslang-compiler` until the public `oreslang` CLI grows a run command.
