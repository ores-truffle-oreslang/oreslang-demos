# Oreslang demos

Runnable example applications for Oreslang.

## Layout

- `cli/` — a pure Oreslang command-line application.
- `desktop-app/` — Oreslang application output rendered in a native Swing desktop window.
- `web-server/` — a local HTTP server whose response bodies are generated by Oreslang entrypoints.

## Requirements

- `oreslang-compiler` on `PATH`, or set `ORESLANG_COMPILER=/path/to/oreslang-compiler`.
- A JDK for the desktop and web host shells.
- Optional: the public `oreslang` CLI for non-executing checks, e.g. `oreslang check cli/main.ores`.

The current Oreslang runtime exposes capability-scoped standard IO, but it does not yet expose first-class desktop-window or HTTP-listener guest APIs. The desktop and web demos therefore keep the application content/logic in `.ores` files and use deliberately small Java host shells only for OS integration. This keeps the demos runnable against the current compiler instead of inventing APIs that do not exist yet.

Each folder has its own README and `run.sh`.
